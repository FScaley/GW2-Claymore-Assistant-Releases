# Claymore Law Asistan

Guild Wars 2 icin Nexus addonu: oyun ici yapay zeka sohbet asistani (Google Gemini).

NPC/lokasyon, crafting tarifi, TP fiyati, waypoint, build ve genel oyun sorularini GW2 Wiki, guide'lar ve GW2 API uzerinden cevaplar; buldugu yerleri harita uzerinde isaretler.

## Kurulum

1. [Nexus](https://raidcore.gg/Nexus) kurulu olmali.
2. [Releases](../../releases/latest) sayfasindan `claymore-asistan.dll` dosyasini indirip oyunun `addons/` klasorune kopyalayin (veya Nexus'tan yukleyin).
3. Oyunda **ALT+C** ile pencereyi acin.
4. Nexus ayarlarindan (CTRL+O > Addons > Claymore Law Asistan) kendi Gemini API anahtarinizi girin. Hesap bilgisi sorulari icin GW2 API anahtari da girilebilir.

Guncellemeler Nexus uzerinden otomatik gelir.
